Developer Environment Health Checker

Project Description

A Python-based tool that checks the health and configuration of a developer environment.

Features

- Python Version Check
- Operating System Check
- Required Software Check
- Network Connectivity Check
- System Information Check
- CSV and JSON Report Generation

Technologies Used

- Python
- Git
- GitHub
- VS Code

Project Structure

developer-environment-health-checker/
├── main.py
├── diagnostics_tool/
├── tests/
├── diagnostics_report.csv
└── diagnostics_report.json

How to Run

python main.py
